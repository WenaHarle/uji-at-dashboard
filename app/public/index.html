Pengaturan Cloudflare yang dibutuhkan

  1. Zero Trust → Networks → Tunnels → tunnel-mu → Public Hostname: ujiat.madewena.com → HTTP → localhost:8900.
  2. Rules → Configuration Rules: bila hostname ujiat.madewena.com dan path diawali /t/, /ws, /mqtt, atau /ota/ → Automatic HTTPS Rewrites off, Always Use HTTPS off (agar tes http:// dan TCP port 80 jalan), Browser Integrity Check off.
  3. Security → Bots: pastikan Bot Fight Mode mati (di paket gratis tidak bisa dikecualikan per path).
  4. Network: WebSockets on (bawaan on).
  5. Cloudflare memutus WebSocket diam ±100 detik → keepalive MQTT ≤ 60 detik (lihat M-12).
